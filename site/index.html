03 / Research workflow

From recording to features.

A transparent overview of the exploratory EEG analysis pipeline currently documented in the repository.

EEG / PIPELINE_001

Turning neural recordings into structured data.

The current workflow uses public EEGBCI motor-imagery recordings and a deliberately modest initial analysis setup. It is a learning and research workflow—not a clinical or real-time system.

PhysioNet EEGBCIPython 3.10+Offline analysis
01
Dataset & event inspection

Load imagery runs and inspect event annotations and usable recordings.

02
Preprocessing & epoching

Standardise channels, filter EEG signals, and create task-related epochs.

03
Spectral feature extraction

Estimate Welch PSD and derive log-power features across delta, theta, alpha, and beta bands.

04
Exploratory model evaluation

Use a subject-independent group holdout with an SVM pipeline; stronger validation is still needed.
